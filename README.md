# Eternal Blizzard

Мод для Minecraft **26.2** (Fabric).

- Днём в Верхнем мире всегда идёт дождь (в холодных биомах это снег).
- Ночью всегда гроза (буря): вокруг игроков много снежинок, а игроки под открытым небом
  замерзают, как в рыхлом снеге (синий оверлей, замедление, урон от холода).
  Спрятаться можно под крышей, а кожаная броня защищает так же, как от рыхлого снега.
- Сон и команда `/weather clear` не помогут: погода возвращается в течение секунды.

## Команды (нужны права оператора)

- `/blizzard start` запускает бурю на 5 минут в любое время суток
- `/blizzard start <секунды>` то же на заданное время
- `/blizzard stop` останавливает бурю, запущенную командой (ночью буря всё равно идёт)

## Требования

- Minecraft 26.2, Fabric Loader 0.19.3+, Fabric API
- Java 25

## Сборка

Локально (нужна JDK 25):

```
./gradlew build
```

Готовый мод: `build/libs/eternal-blizzard-1.0.0.jar` (файл с `-sources` не нужен).

На GitHub сборка запускается сама при каждом push: Actions → build → Artifacts.

## Настройка

Константы в `src/main/java/com/eternalsnow/EternalBlizzard.java`:
границы ночи, скорость заморозки (`FREEZE_PER_TICK`), интервал проверки погоды.
